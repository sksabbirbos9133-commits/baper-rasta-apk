# Baper Rasta — Android App

Android wrapper app for the free browser game **Baper Rasta (বাপের রাস্তা)** — a satirical arcade game set on the streets of Dhaka. Drive a battery auto-rickshaw, crash into traffic to raise the National Loss, keep away from buses and trucks, and escape the angry crowd.

- Original game: https://baperrasta.com/
- Made by Omar Faruqe Riyad
- This app simply opens the official game website in full screen, so it always plays the latest version. It was made with the game maker's permission for playing on a low-end phone.
- Download the APK from the Releases page.
